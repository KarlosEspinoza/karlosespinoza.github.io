# Semana 3 - Contenedores y concepto de proceso (U1-U2)

## Antes de la clase (aprendizaje invertido)

Que es un contenedor: namespaces y cgroups (lectura o video). Como el SO aísla procesos.

## Durante la clase (aprendizaje activo)

Demo de Docker como aplicación de conceptos del SO (aislamiento de procesos y recursos). Modelamos el concepto de proceso sobre nuestro caso: que datos definen un pedido.

## Tu proyecto esta semana

- Crea la clase `Pedido.java` con los datos de un pedido de tu dominio.
- Explica en `BITACORA.md` que es un contenedor (namespaces y cgroups) con tus palabras.
- Opcional: ejecuta tu servidor dentro de un contenedor Docker para ver el aislamiento.
- Haz push de tus cambios.
