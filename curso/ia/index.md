## El caso del semestre

Todo el curso gira alrededor de un solo sistema que construyes tú mismo: un **clasificador de piezas sobre banda transportadora**. Lee la señal de un sensor, decide con un modelo de aprendizaje de máquina de qué tipo es la pieza y acciona un actuador para enrutarla. Cada unidad le agrega una capa, hasta llegar al bucle completo sensores -> Python -> modelo -> PLC -> actuadores.
