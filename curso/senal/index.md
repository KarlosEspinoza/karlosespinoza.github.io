## El caso del taller

Las 7 horas giran alrededor de un solo sistema que construyes tú mismo: un **clasificador de tres piezas**. Un sensor lee la pieza, Python le extrae unas cuantas características, un modelo de aprendizaje de máquina decide de qué tipo es y un LED RGB muestra la decisión con un color. Las piezas son las mismas para todos: cartulina blanca, cartulina negra y papel aluminio.

Es la versión mínima del clasificador de piezas sobre banda transportadora del curso de [Inteligencia Artificial](/curso/ia/), que llevas el siguiente ciclo. El kit es el mismo y los programas se llaman igual, a propósito.
